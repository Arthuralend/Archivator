# Archivator

Архиватор для macOS (Apple Silicon M1/M2/M3) в классическом стиле: панель с крупными иконками, адресная строка, таблица файлов, строка состояния.
Интерфейс написан на **React**, приложение работает на **Electron**, сами архивы обрабатывает официальный консольный **7-Zip (`7zz`)**.

| Формат | Открыть / распаковать | Создать / добавить / удалить |
|---|---|---|
| ZIP | ✅ | ✅ (пароль AES-256) |
| 7Z  | ✅ | ✅ (пароль, шифрование имён, solid) |
| RAR / RAR5 | ✅ | ⚠️ только если установлен `rar` (`brew install rar`). Формат RAR закрытый, создавать его может только утилита RARLAB |
| TAR, GZ, BZ2, XZ, ISO, CAB | ✅ | — |

## Возможности
- Просмотр папок на диске и содержимого архивов как обычных папок (двойной клик, `..`, Backspace — вверх)
- Добавить, Извлечь, Тест, Просмотр (открывает файл из архива без полной распаковки), Удалить из архива, Найти, Мастер, Инфо
- Пароли: запрос пароля при открытии и распаковке зашифрованных архивов
- Уровни сжатия, разбиение на тома, удаление файлов после упаковки
- Drag & drop: перетащите файлы в окно, чтобы создать архив; архив — чтобы открыть его
- Ассоциация с .zip/.rar/.7z: открытие двойным кликом в Finder (после сборки .app)
- Прогресс операций и кнопка «Отмена»

## Запуск в режиме разработки (на Mac)
```bash
npm install
npm run fetch-7z     # скачает 7zz с 7-zip.org в ./bin (или: brew install sevenzip)
npm run dev
```

## Сборка .dmg для Apple Silicon
```bash
npm run dist         # результат — в папке release/ (Archivator-1.0.0-arm64.dmg)
```
Приложение не подписано, поэтому при первом запуске: правый клик → «Открыть», либо
```bash
xattr -cr /Applications/Archivator.app
```

## Структура
- `electron/main.cjs` — окно, меню, IPC
- `electron/archive.cjs` — вызовы `7zz`/`rar`, разбор вывода `7zz l -slt`
- `electron/preload.cjs` — безопасный мост `window.api`
- `src/App.tsx` — главное окно; `src/dialogs.tsx` — диалоги; `src/icons.tsx` — SVG-иконки
